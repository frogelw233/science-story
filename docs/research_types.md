# 按成果问题选择解释与核查方式

这是一份条件式参考，不是每篇都要填写的分类表。读过来源后，先判断成果的核心主张，以及它凭什么成立，再选用相关项；跨学科成果可以组合，未涉及的项直接略过。标题中的“重大”“首次”“突破”不能代替对新进展的核验。机构、装置或学科名称不决定解释流程。

| 何时适用 | 给普通读者讲清的推进 | 证据与结论的关键核查 | 边界如何表达 |
| --- | --- | --- | --- |
| **实验或观测**：核心新意来自获得、比较或分析实际观察资料。 | 为解答什么问题，研究者比较了什么；哪些变化、差别或模式构成线索；怎样从线索得到结论。仪器机制只讲理解证据所必需的部分。 | 数据来源、样本与选择、对照或参照、测量与分析条件、误差和替代解释。区分直接记录与经模型推断；观测关联本身不构成因果结论。 | 结论在哪些对象和条件下成立，误差或混杂影响什么；不要把未来测量能力写成此次结果。 |
| **理论或数学**：核心新意是定理、证明、理论模型、预测或反例。 | 原问题怎样用容易辨认的例子提出；关键定义或假设是什么；论证中哪一步打开了此前的困难；结论改变了什么。可以解释证明思路，不声称通俗例子已完成证明。 | 对照正式命题、前提、量词、证明状态与来源版本。区分已证明结论、猜想、近似推导和数值支持；模型预测不等于已观察到现象。数学结论以证明为依据，不强行附加统计置信区间。 | 说明哪些前提不可省略、覆盖什么情形；审查者无法独立验证完整证明时如实报告，不能以故事流畅或模拟成功代替证明。 |
| **计算方法或工具**：核心主张是某个方法更有效、更准、更快或能解决新任务。 | 以前要完成什么任务、遇到什么限制，新方法改变哪一步；用可读的输入—处理—输出例子帮助理解，再解释比较结果。 | 测试任务与数据、基线及其设置、数据划分与泄漏风险、评价指标、资源成本、公平比较和复现范围。新方法涉及理论保证时同时选理论项；涉及用户或现实环境数据时同时选实验项。 | 基准得分只支持相应测试条件；说明测试之外的泛化、真实部署及资源代价是否验证。不要把单项最佳分数推广成普遍能力。 |
| **证据综合**：核心新意来自系统综述、元分析或对多项研究的组织比较。 | 单篇研究为什么给不出清楚答案；研究者怎样选取和整合资料；一致之处与分歧怎样改变总体认识。 | 检索与纳入范围、研究质量、重复样本、异质性、偏倚和整合方法；区分“未找到证据”与“证明没有效果”。原研究限制不会因合并而自动消失。 | 指明适用群体、环境、研究质量与缺口；较多研究不自动意味着确定结论，综合关联不能升级为因果证明。 |
| **历史或解释性研究**：核心新意来自材料发现、文本分析、概念重构或对社会文化现象的解释。 | 以前怎样理解某个问题；什么资料、比较或解释改变了这一理解；新的读法为何有依据，又有哪些竞争解释。 | 原始材料的出处、年代、作者与语境，引用/翻译及选择方式，论证与材料之间的关系。区分当事人的说法、可确证事件和研究者解释。 | 交代材料缺失、代表性、解释争议及观点适用范围；不能因叙事完整就把争议写成定论，也不必伪装成实验或量化结果。 |

共用的最小问题是：**这项工作在回答什么；凭什么多知道了一点；究竟多知道了什么；还不能据此说什么。** 入口中的读者关联属于传播选择，不能替代以上学术依据。

`research_link` 用一句常用话连接入口问题与本次研究实际贡献。`question/development/resolution` 记录文章的认识推进，可以跨多段、采用比较或论证结构；它不是要求原研究真实发生过同样的戏剧顺序。按材料安排段落和图片，避免为了满足模板而增加无关术语、流程图或人物。
