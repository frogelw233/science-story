# 产品与验收合同 · 0.4

输入公开科研或学术成果的发布文章、论文、正文或材料链接，输出普通成年人愿意进入、能沿文中解释理解的完整中文图文科普。范围包含大科学装置及其他实验、观测、理论、数学、计算、证据综合和解释性研究。具体领域的处理方式由材料决定；“重大”或“突破”须有证据，不因输入这样命名就照用。

当前获准AI宿主负责研究、写作和语义审查，Python核心负责记录与确定性导出，无需另购API、服务器或GPU。支持URL、粘贴及本地UTF-8文本；PDF可由宿主已有能力读取，不能把局部可访问内容当作已取得全文。

文章先建立真实阅读理由，以一个能够兑现或诚实收窄的真实悬念贯穿全文。写作前从结论反向列出必要概念与关系，并在使用前讲清；每个叙事beat必须记录并实际完成一项`advance`（阶段整体推进，不要求每句或每段增加新事实，允许消化与回看），使读者的问题、证据或认识向答案推进。故事可沿实验过程、问题解决、证明思路、方法比较或材料解释展开；不要求人物、轶事、仪器信号、拟合参数、固定六段或未来未解问题。

关键解释优先正面说明对象是什么以及怎样参与本文问题。句子明确主体、动作、对象和判断依据；对象或系统本身的变化、工具观测到的现象、研究者采用的分类以及由证据作出的推断必须区分。分别起作用的机制、条件或功能分别解释各自解决的问题。因果、统计支持、数学证明和学术解释不可互相冒充。

完整科普正文默认按3000—4000字安排，最长4000字；短题材不为凑足3000字填充，用户另有明确篇幅要求时优先遵从并记录。段落和句子不设机械字数配额。压缩先减支线与重复，不能删掉主线必要解释或提高信息密度；仍放不下时收窄问题或分篇，不能把前提藏进图注或选读。字数上限是本项目的交付约定，不是经研究证明的阅读阈值。图片数量仍为编辑选择。图片必须帮助看见对象、关系、过程、比较、论证或相关场景，不规定装置照片和示意图配比。公开原始材料仅在许可和任务授权允许时分发；图片署名与使用条件始终保留。

每个完整运行目录包含article.html、article.md、assets、story.json、sources.json、evidence.json、editorial_plan.json、checks.json、audience-checks.json、run_manifest.json、`reviews/language-story.json`及实际完成的其他审查记录。figure_specs.json仅在使用通用绘图命令时需要；专用绘图代码放运行目录，不能成为共享运行时的前置条件。

硬性条件：正文符合默认上限或已记录的用户篇幅要求，正文完整，核心主张与依据可核对、适用条件准确、必要概念先于使用、关键关系没有未解决的实质误读、每个beat实际推进中心问题、图像实际存在且性质明确、每幅图在HTML和Markdown中都有清楚标注的本地原图入口、HTML/Markdown可解析、统一AI声明在所有来源与署名之后且仅有一次。错误输入明确失败。报告实际执行的结构、事实/论证、独立语言故事、隔离读者、视觉检查及受控回归，不把字段齐全、模型自评或合成样例当成真实跨领域端到端验证。

从成稿反向审查标题、结论、论述、类比、图注和图形暗示。独立语言故事审查只看成品和图片：先从结论倒查缺失前提，再独立改述关键句，寻找主体、动作、对象、物理变化、观测、分类、推断及并列机制之间的歧义，并逐项核实beat的`advance`。隔离读者审查另依据正文说明阅读理由和推断或论证桥梁；两类审查均不提供作者答案和证据库。默认两轮自动修订，未解决的核心问题不得报完成。无需真人或专家逐篇审核作为起步条件；未做真人兴趣、理解和完读测试时明确未验证。

AI声明唯一源为src/science_story/templates/disclosure.txt，沿用已确定的统一文本。没有授权不创建远程仓库、推送、发布、发消息；公开包不含私人聊天、账户信息和私人原始输入。

适用范围是产品目标，不代表所有学科均已验证。完整真实样例与结构/路由测试的范围分别列在README及验收报告。现存案例的知识和专用绘图只属于该例，通用流程不得隐式载入。
