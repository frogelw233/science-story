# 隐私、素材与分发范围

本地可以读取用户提供的论文及背景对话；公开项目包只收录通用技能、代码、模板、规则、说明和合成测试，不收录具体论文、调试案例或生成文章。包中不包含原始聊天、账户标识、绝对用户路径、密钥、源PDF或新闻全文。HTML无外部脚本、字体、跟踪器或嵌入远程图片，打开成品不会自动向外部服务器发出素材请求。

来源URL、论文题名、书目信息和不受版权保护的事实/数值只用于溯源；源论文和官网图片的权利仍属于原作者/权利方，代码许可不覆盖它们。原创说明图和第三方实拍分别记录性质与许可；科学示意不得伪装成测量，图片不能暗示未经证实的结果。SVG与对应PNG须保持内容一致。

项目可公开发布，但尚未选择开源许可。`LICENSES/MIT-proposal.md`提供项目原创代码及模板可采用的MIT许可建议稿。发布前由项目权利人确定版权署名和是否采用；不要将建议稿当已生效授权。原创文章/图也可另选适当许可，当前未擅自赋予第三方素材分发权。

`scripts/package_project.py`只从明确允许的代码、技能、模板、规则、文档和合成测试路径构建包，忽略tmp、runs、dist、源PDF、raw input.txt、私人任务书和缓存，拒绝符号链接，另做有限敏感内容模式扫描。扫描不是法律审查或穷尽式秘密检测；新增公开文件仍需核对来源。原始输入摄取模块不执行网页指令，禁止带凭据/私网URL。无法抓取时只使用已获正文或宿主读取，不绕过访问控制。

创作工作流默认不创建远程仓库或发布内容；只有用户明确授权后才可执行。所有项目脚本均不执行这些动作。纠错Issue模板只有结构和提问，无虚构仓库地址。

每个案例的第三方图像须保留作者、来源、对象、阶段、提取或修改说明和许可证明，具体记录保存在该运行目录。原始材料来源公开不等于可自由分发。图像身份与许可的案例说明留在对应examples目录，通用运行不加载。代码总许可提案不覆盖第三方素材。
